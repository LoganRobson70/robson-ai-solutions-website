# Robson AI Solutions Brand Guardrails

Apply these rules to every page, component, and content update in this repository.

## 1. Brand Identity
- Positioning: intelligence-led consultancy for construction, asset management, maintenance planning, and compliance.
- Brand qualities: trust, clarity, structure, evidence-based decision making.
- Avoid gimmicks, novelty effects, and decorative "AI" styling.

## 2. Logo System
- Primary mark (source of truth): `assets/logo-simple-r.svg`
- Rules for primary mark:
  - single solid form
  - flat colour only
  - no segmentation
  - no gradients, shadows, or effects
- Approved raster derivative: `assets/robson-ai-icon.png`
- Rules for raster derivative:
  - must be exported from `assets/logo-simple-r.svg`
  - no geometry redraw
  - no extra tiles, gradients, shadows, or effects
- Use `assets/robson-ai-icon.png` for:
  - website header logo image
  - navigation icon contexts
  - favicon and apple-touch-icon
  - small-size raster UI placements
- Use `assets/logo-simple-r.svg` for:
  - master source and vector-first contexts
  - app icon generation source
- Secondary mark: `assets/logo-constructed-r.svg`
- Use secondary mark only for corporate emphasis contexts such as report covers or statement panels.
- Never display both logo versions together.
- If unsure, default to the primary mark.

## 3. Colour Palette (Strict)
- Deep Navy: `#002D62`
- White: `#FFFFFF`
- Steel Blue: `#2F6FA7`
- Soft Grey: `#F5F5F5`
- Amber Orange: `#E8A400`
- Accent usage rule: one accent colour only per section.
- No gradients in the master layout.
- Preserve accessible contrast.

## 4. Typography
- Headings: Montserrat (Bold/SemiBold)
- Body: Open Sans (Regular)
- Buttons and UI labels: Poppins or Montserrat Medium
- Keep hierarchy consistent (`H1 -> H2 -> body`).
- Use UK English spelling.

## 5. Layout and Structure
- Use clean modular sections.
- Use subtle rounded cards/panels with generous white space.
- Navigation must be simple and predictable with no more than six primary items.
- Preferred page order:
  1. Hero / Introduction
  2. About / Credibility
  3. Solutions / Services
  4. Use Cases / Examples
  5. Resources / Thought Leadership
  6. Contact / Call to Action

## 6. Imagery and Icons
- Prefer built-environment and digital-intelligence imagery in cool blue/neutral grading.
- Avoid robots, abstract neon visuals, and stock "AI brain" imagery.
- Icons must be simple, flat or line-based, and visually consistent.

## 7. Tone of Voice
- Professional, direct, evidence-led, and calm.
- Prefer terms such as:
  - evidence-based
  - structured
  - intelligence-led
  - compliance-focused
  - decision support
- Avoid hype language and exaggerated claims.

## 8. Enforcement Checklist
Before finishing any website change, confirm:
- Palette and typography are compliant.
- Logo choice matches context and does not conflict with logo pairing rules.
- Layout stays minimal, clear, and section-ordered.
- UK English spelling is used.
- Conflicting visual embellishments are removed.
